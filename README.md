## 🚀 Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/pattelapurna/html-resume.git

2. Navigate to the project folder:

   ```bash
   cd html-resume
   ```
3. Open `index.html` directly in your browser
   (double-click it or right-click → open with browser)

✅ That’s it.
